# المعمارية

يتولى `GameBootstrap` تركيب المشهد وربط الأنظمة. يحتفظ `GameManager` بحالة الجولة والسرعة والنقاط والمضاعف والمهمة والحفظ ولا يعتمد على تفاصيل العرض. يقرأ `RunnerInput` الإدخال من لوحة المفاتيح أو اللمس ويحوّله إلى أوامر موحدة، ثم يطبق `RunnerController` الأوامر على `CharacterController`.

يحمّل `RunnerCharacterVisual` نموذج السحلية الثلاثي الأبعاد من Resources ويضبط حجمه واتجاهه وخامته، ثم يربطه بـ`MeshyHeroAnimator` لمزج مقاطع FBX مع حركات Humanoid الإجرائية. تبقى أسماء بعض الملفات الداخلية القديمة كما هي للحفاظ على توافق الاستيراد، ويعمل `JordanianHeroBuilder` و`JordanianHeroRig` كمسار احتياطي فقط.

ينشئ `TrackManager` عددًا ثابتًا من المقاطع ويعيد تدويرها أمام اللاعب. يتولى `FantasyThemeBuilder` إنشاء الجزر العائمة والبوابات والكريستالات والمعالم الخيالية لكل مقطع. يحتفظ `WorldObjectPool` بالعقبات والعملات والقدرات ويعيد استخدامها، لذلك لا يوجد إنشاء وحذف متكرر أثناء الجري. يبني `RuntimeHud` الواجهة المتجاوبة، بينما يولّد `GameAudio` المؤثرات والموسيقى الأصلية دون ملفات صوت خارجية.

## تدفق الجولة

`Ready -> Countdown -> Running -> Paused -> Running -> GameOver`

لا ينتقل اللاعب من `GameOver` مباشرة إلى `Running`؛ زر المحاولة يعيد تحميل مشهد Bootstrap ليبدأ كل نظام بحالة نظيفة.

## استبدال الرسومات

معظم البيئة منخفضة المضلعات ومولّدة من Primitives، بينما الشخصية الحالية نموذج FBX مفصل لسحلية كرتونية. لاستبدالها لاحقًا مع إبقاء المنطق:

1. استورد نموذج Humanoid مرخصًا وأنشئ له Animator Controller.
2. استبدل إنشاء `RunnerCharacterVisual` في `GameBootstrap` فقط، مع إبقاء `RunnerController` و`CharacterController`.
3. اربط حالات الجري والقفز والانزلاق بالخصائص العامة في `RunnerController`، أو اترك `RunnerCharacterVisual` كمرجع للتنفيذ.
4. لا تغيّر مكونات `Hazard` و`PooledPickup` أو أحجام المصادمات قبل اختبار اللعب على الهاتف.

## التوسعة المقترحة

- إضافة Addressables للأصول الكبيرة.
- إضافة Unity Gaming Services للنتائج السحابية.
- فصل واجهة المستخدم إلى Prefabs عند إدخال تصميم فني نهائي.
- إضافة متجر شخصيات ولوحات باستخدام ScriptableObjects.
- إضافة نظام أحداث يومية مرتبط بخادم بعد اختيار خدمة Backend.
