# فتح إصدار الشخصية الأردنية عالية التفاصيل

هذه النسخة مشروع مستقل باسم **DesertDash3D_AmmanJordanianHero** عند فك الضغط. لا تنسخ الملفات فوق نسخة عمّان السابقة يدويًا.

1. أغلق مشروع Desert Dash القديم في Unity.
2. فك ضغط `DesertDash3D_AmmanJordanianHero.zip` في مجلد جديد.
3. من Unity Hub اختر `Add > Add project from disk`.
4. اختر مجلد `DesertDash3D_AmmanJordanianHero` الذي يحتوي مباشرة على `Assets` و`Packages` و`ProjectSettings`.
5. افتحه باستخدام Unity `6000.0.80f1` وانتظر انتهاء الاستيراد.
6. اختر `Amman Run > Apply Recommended Settings`.
7. اختر `Amman Run > Validate Project`.
8. افتح `Assets/DesertDash/Scenes/Bootstrap.unity` واضغط Play.

## ماذا سترى

- تظهر كاميرا استعراض أمامية للشخصية الأردنية عالية التفاصيل قبل بدء الجولة.
- يظهر الشماغ الأحمر والأبيض والحقيبة والساعة والجاكيت والحذاء المفصل.
- عند الضغط على `START RUN` يظهر عد تنازلي من 3.
- تظهر المهمة الحالية أعلى الشاشة، والمضاعف إلى اليسار.
- قدرات `BOARD` و`MAGNET` و`2X BOOST` تظهر مع مؤقت عند التقاطها.

## ملاحظة عن الحفظ

تستخدم نسخة عمّان مفتاح حفظ مستقلًا، لذلك لا تغيّر نتائج نسخة Neon Sands ولا تستوردها تلقائيًا.

## إذا ظهرت أخطاء

افتح `Window > General > Console`، ثم أرسل صورة كاملة وأول رسالة حمراء. لا تثبت حزمًا خارجية؛ المشروع لا يحتاج إليها.
