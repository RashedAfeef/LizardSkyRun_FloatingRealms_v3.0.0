# شخصية السحلية الثلاثية الأبعاد

## النموذج النشط

يحمّل المشروع ملف `JordanianHero_Meshy_Animated_Full.fbx` تلقائيًا من Resources. اسم الأصل قديم، لكن النموذج والخامة هما شخصية السحلية المرفقة: جلد مرقّط، عينان حمراوان، ذيل وملابس سوداء وبيضاء. أبقينا الاسم والمسار لتفادي كسر الـAvatar ومقاطع الحركة وإعدادات الاستيراد.

يتولى `RunnerCharacterVisual` تصحيح اتجاه النموذج، ضبط ارتفاعه إلى `2.16` متر وإنزاله إلى مستوى الأرض. إذا فشل تحميل النموذج أو الخامة أو الحركات، تظهر رسالة واضحة في Console ويُستخدم النموذج الإجرائي الاحتياطي.

## الخامة

تُحمّل `JordanianHero_BaseColor.png` تلقائيًا وتُطبق على جميع أجزاء النموذج. يستخدم المشروع Shader كرتونيًا بثلاث درجات إضاءة مع ظلال زرقاء وحافة سماوية، وهو مناسب لألوان البيئة الخيالية ويُظهر تفاصيل الجلد والعينين والذيل بوضوح.

## الحركات

- مقاطع FBX الأساسية: `Running` و`Run_03` و`Walking`.
- طبقة إجرائية للوقوف والتنفس، بدء الجري، السرعة العالية، القفز، الهبوط وامتصاص الصدمة.
- حركات اللعب: الميل عند تبديل المسار، الانزلاق متعدد المراحل، ركوب اللوح، التعثر، السقوط والاحتفال.
- Root Motion معطل لأن `RunnerController` مسؤول عن انتقال اللاعب بين المسارات والحركة الأمامية.

## الأداء

النموذج عالي التفاصيل ومناسب لمعاينة الحاسوب. لاختبار الهاتف استخدم Unity Profiler وراقب المثلثات والذاكرة. يمكن لاحقًا إنشاء نسخة Remesh أخف مع الحفاظ على أسماء العظام والخامات ومسار الملف.
